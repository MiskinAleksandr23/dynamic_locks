# Все 14 сценариев на 8 потоках — 18 сентября 2026

Первичный отбор: один повтор каждой из трёх реализаций, 42 последовательных запуска. Ускорение = wall_s(fixed) / wall_s(варианта) при одинаковом числе запросов и одинаковых входных трассах. Это одиночные измерения, а не оценка статистической значимости. Порядок сценариев ниже — по меньшему из двух ускорений balanced и DP.

8 рабочих потоков; 64 блокировки; статистика примерно на каждом 64-м запросе; проверка необходимости перестройки раз в 30 с. Адаптивная реализация дополнительно имеет фоновый поток. В wall_s входят холодный старт, сбор статистики, перестройки и завершение. Перед серией прошли 6/6 CTest; после каждого замера проверен весь итоговый массив: 42/42. Генерация трасс, обнуление данных и проверка результата вынесены за таймер одинаково для всех реализаций.

Каждый запрос читает весь диапазон и изменяет одну ячейку внутри него. Лимит хранимой трассы — 2²⁰ запросов на фазу суммарно по потокам; трасса повторяется циклически. Фазы переключаются после заданного числа операций, а не по времени. В shift, exchange_range и moving_variable_range остаётся по одной реальной смене нагрузки, как в предыдущих измерениях. Несколько смен в одном запуске здесь ещё не проверяются.
